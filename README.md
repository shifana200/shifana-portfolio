# Shifana Portfolio

Build a modern, professional, recruiter-focused personal portfolio website for **Shifana**, a **Full Stack MERN Developer**, using React.

The portfolio will be used primarily for job applications in the UAE, especially for Full Stack Developer, MERN Stack Developer, Frontend Developer, and Backend Developer positions.

The website must look professional, clean, modern, trustworthy, and technically impressive without being overly flashy.

## 1. Technology Requirements

Use:

* React
* TypeScript if supported
* Vite
* Tailwind CSS
* React Router if routing is needed
* Lucide React or another lightweight icon library

Do NOT use unnecessary heavy libraries.

The code should be:

* Clean
* Modular
* Reusable
* Easy to understand
* Easy to modify later
* Component-based
* Production-ready

Create reusable components for sections such as Navbar, Hero, About, Skills, Projects, Contact, and Footer.

## 2. Most Important Requirement — RESPONSIVE DESIGN

The website MUST be fully responsive.

Recruiters may open the portfolio on:

* Desktop
* Laptop
* Tablet
* iPad
* Android phone
* iPhone
* Small mobile screens

Design mobile-first and progressively enhance for larger screens.

There must be NO:

* Horizontal scrolling
* Overflowing text
* Broken layouts
* Overlapping elements
* Tiny unreadable text
* Buttons going outside the screen
* Images being cropped incorrectly
* Desktop-only navigation

Test the layout conceptually at approximately:

* 320px
* 375px
* 414px
* 768px
* 1024px
* 1280px
* 1440px+

The navigation should transform into a clean mobile menu on smaller screens.

Cards, grids, typography, spacing, buttons, images, and sections should all adapt appropriately to screen size.

## 3. Overall Design Direction

Create a sophisticated developer portfolio rather than a generic template.

Design style:

* Minimal
* Elegant
* Modern
* Professional
* Clean
* Slightly premium
* Recruiter-friendly
* Excellent readability

Avoid excessive animations, excessive gradients, excessive glassmorphism, huge decorative elements, or anything that makes the site look like a template.

Use a refined color palette with:

* Deep navy / dark text
* White or very light background
* Subtle teal accent color
* Soft neutral gray tones

The design should feel suitable for a professional software developer.

Use generous whitespace and strong visual hierarchy.

Animations should be subtle and purposeful.

Use smooth scrolling and small hover/focus transitions.

Respect `prefers-reduced-motion`.

## 17. PERFORMANCE

Keep the website lightweight and fast.

Optimize images.

Lazy-load project images where appropriate.

Avoid unnecessary dependencies.

Avoid large background videos.

Avoid excessive animation.

The website should load quickly even on mobile internet connections.

## 18. ANIMATIONS

Use subtle animations only.

Examples:

* Fade-in on section entrance
* Slight card hover
* Button hover
* Smooth scrolling
* Small navbar transition

Do NOT use:

* Excessive bouncing
* Large parallax effects
* Constant moving backgrounds
* Distracting animations

The portfolio should prioritize professionalism over visual effects.

## 19. RESPONSIVE BREAKPOINT BEHAVIOR

Desktop:

Use a spacious two-column layout where appropriate.

Tablet:

Reduce spacing and adjust grids.

Mobile:

Use one-column layouts.

Ensure:

* Headings scale down
* Paragraphs remain readable
* Cards become full width
* Buttons can stack when necessary
* Navigation becomes a mobile menu
* Images scale correctly
* No content touches the screen edges
* Sections have appropriate vertical spacing

Use responsive Tailwind classes consistently.
